### ⟬ More About Me ⟭
I enjoy making games with cinematic lighting and a more realistic visual style, but I don't particularly enjoy building large environments from scratch. That's one reason I find 2.5D games especially interesting to work on.

As a player, I find games with a bit of grind surprisingly enjoyable. There's something satisfying about working toward a goal and finally seeing it through.
